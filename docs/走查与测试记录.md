## 八、帖子编辑/删除与评论删除（2026-11-23，本机验证）

清单外补的功能缺口：作者不能编辑/删除自己的帖子，评论没有删除入口。

**实现**：

- `PUT /posts/{id}`：作者编辑；重新校验（标题/正文/地点/图片规则），事务内重挂主题与图片，按 `random.post.auto-approve` 决定回到 `PENDING` 还是 `ONLINE`；
- `DELETE /posts/{id}`：作者或管理员，软删为 `DELETED` 并广播状态事件（搜索索引同步）；
- 前端：详情页作者可见「编辑/删除」；编辑复用发布页（`/publish?edit=id`）并预填原内容；
- 评论行：本人或管理员可见「删除」，删除后本地移除并同步评论数。

**本机验证**（localhost:5191 + 8080）：

**过程中修掉的自造 bug**：

- `@OptionalAuth` 被新方法挤走 → 匿名看详情 401（测试先红后绿，14/14 通过）；

## 十二、被纠正：列表缩略图溢出（2026-11-23）

**用户反馈**：首页卡片配图撑破容器，压住下一张卡片的文字。

**原因**：`.thumb` 固定高度 132px 但没有 `overflow: hidden`；图片规则依赖 `.thumb img` 存在，一旦缺失或被覆盖，图片按原始尺寸撑破容器。

**修复**：`.thumb` 加 `overflow: hidden`，图片加 `min-height: 0`。

**验证**：

```
缩略图容器 132px / 图片 132px ✓
图片底边 358 < 下一卡顶边 447（不重叠）✓
1280 / 375 横向溢出均为 0 ✓
详情页画廊图 149px ✓
控制台 [] ✓
```

**防复发**：新增 `frontend/e2e/check-layout.cjs`——往首页注入一张 800×600 的图，检查图片是否撑破、卡片是否互压、双宽度是否横向溢出。实测把 `.thumb img` 规则删掉会报 2 个问题，恢复后通过。规则写进 `AGENTS.md` 的交差前检查。
