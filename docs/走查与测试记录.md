## 一、测试人员（bug-hunter）发现

| 等级 | 问题 | 状态 |
|---|---|---|
| high | 登录限流可用 `X-Forwarded-For` 绕过（nginx 追加、backend 直连可伪造） | ✅ 已修：nginx 覆盖 XFF；backend 不再对外发布端口 |
| medium | 作者看自己的待审帖，点赞/评论/路线报「帖子不存在」 | ✅ 已修：路线接口对作者放行；页面隐藏互动入口并提示「审核中」 |
| medium | 挂 7–9 个地点的帖子，路线必然 400（发帖上限 9、寻路上限 6） | ✅ 已修：寻路上限统一为 9 |
| medium | DRAFT 草稿卡死：不能发布、不能删除 | ✅ 已修：状态机允许 DRAFT→PENDING/ONLINE/DELETED |
| medium | `GET /posts/abc`、未知接口、缺参数统一 500 | ✅ 已修：分别映射为 400/404/405 |
| low | 正文 48KB 与 20001 字契约不一致；校验文案英文 | ⬜ 未修（列入待办） |
| low | 浏览数恒 0 | ✅ 已修：详情自增、列表批量读 |
| low | 搜索页不读取 URL 的 q，链接不可分享 | ✅ 已修：从 query 初始化并回写 URL |

正常项（抽测 110 次请求 + 12 个页面）：未登录写接口 401、假/登出 token 401、普通用户调后台 403、删他人评论 403、封禁用户 401、各类超长与非法参数被拒、分类打分 404、重复点赞幂等、并发同名注册仅 1 成功、搜索与 XSS 已转义、非图片/伪造类型/超 5MB 上传被拒、写操作第 31 次 429。
