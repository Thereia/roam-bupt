## 七、可点击元素审计（2026-11-23）

**动机**：用户反馈地点页「打分」「到这里怎么走」看着能点却没反应。这类问题两轮子代理都没当成缺陷，所以补一次机械化审计。

**方法**：用 Playwright 遍历 11 个页面（首页/地点列表/地点详情/帖子/路线/搜索/发布/收藏/通知/个人主页/后台），抓出所有可见的 `button`、`a`、`[role=button]`，分类为：

- `link`：带有效 href；
- `ok`：可用的 button；
- `disabled`：禁用（要求有 title 或语义上合理）；
- `dead-link`：href 为空/`#`/`javascript:`；
- `pointer-only`：`cursor:pointer` 但不是 a/button。

脚本：`frontend/e2e/audit-clickable.js`（需要本地装 playwright，`channel: 'msedge'`）。

**结果**：

| 阶段 | link | ok | disabled | dead-link | pointer-only |
|---|---|---|---|---|---|
| 审计前 | 174 | 65 | 41 | 0 | 0 |
| 修复后 | 174 | 103 | 3 | 0 | 0 |

剩下的 3 个禁用都合理：地点列表第一页的「上一页」、帖子页空评论框的「发表」、路线页未选地点的「规划路线」。

**这一轮补上的“假按钮”**：

- 列表卡片「收藏」→ 真收藏/取消，计数同步；「分享」→ 复制链接；
- 详情页「评论 N」→ 滚动到评论区；「分享」→ 复制链接；
- 地点页「打分」「到这里怎么走」→ 见第六节。

**验证**：

## 八、帖子编辑/删除与评论删除（2026-11-23，本机验证）

清单外补的功能缺口：作者不能编辑/删除自己的帖子，评论没有删除入口。

**实现**：

- `PUT /posts/{id}`：作者编辑；重新校验（标题/正文/地点/图片规则），事务内重挂主题与图片，按 `random.post.auto-approve` 决定回到 `PENDING` 还是 `ONLINE`；
- `DELETE /posts/{id}`：作者或管理员，软删为 `DELETED` 并广播状态事件（搜索索引同步）；
- 前端：详情页作者可见「编辑/删除」；编辑复用发布页（`/publish?edit=id`）并预填原内容；
- 评论行：本人或管理员可见「删除」，删除后本地移除并同步评论数。

**本机验证**（localhost:5191 + 8080）：

```
编辑预填            原标题正确带出 ✓
保存后详情标题       已更新 ✓
删除后详情接口       404 ✓
评论删除按钮         本人可见 ✓，删除后列表为 0 ✓
非作者看详情         无「编辑/删除」✓
控制台              [] ✓
```

**过程中修掉的自造 bug**：

- `@OptionalAuth` 被新方法挤走 → 匿名看详情 401（测试先红后绿，14/14 通过）；
- 详情页漏 `import deletePost/deleteComment/showNotice` → 点删除无反应（ReferenceError 被 catch 吞掉）；
- 评论删除误调用不存在的 `loadComments()` → 改为本地过滤。

**待做**：`PUT /posts/{id}/publish`（草稿发布）仍未实现，草稿箱 UI 也未做；VM 部署待补。
