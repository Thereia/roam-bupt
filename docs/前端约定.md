# 前端约定（frontend/）

> 适用：仓库根下 `frontend/` 的全部代码。开工前先读本文；接口只认 `docs/API-契约.md`。
> 视觉基线：`docs/mockup.html`（可直接在浏览器打开对照）。

## 1. 技术栈

- Vue 3（Composition API）+ Vite 5 + vue-router 4 + axios
- **不引 UI 组件库**，组件手写；**不引 Pinia**，用一个 `reactive` 模块存登录态就够
- Node 22 / npm 10（本机已装）

## 3. 请求层（`api/request.js`）

- `baseURL = '/api/v1'`，dev 由 Vite 代理到 `localhost:8080`。
- 请求拦截：从 `localStorage.roam_token` 取 token，非空则加 `Authorization: Bearer <token>`。
- 响应拦截：后端统一返回 `{code,message,data}`。
  - `code === 0` → 直接把 `data` 交给调用方；
  - 否则抛 `ApiError(code, message)`，不吞异常。
- HTTP 错误处理：

| 状态 | 处理 |
|---|---|
| 401 | 清 `roam_token` 与用户信息；若当前不在 `/login` 则跳 `/login` |
| 403 | 提示「没有权限」 |
| 429 | 提示「操作过于频繁，请稍后再试」 |
| 503 | **不清 token**，提示「服务暂时不可用，请稍后重试」 |
| 其他 | 提示 message 或「请求失败」 |

## 4. 登录态（`store/user.js`）

```js
export const userStore = reactive({
  token: localStorage.getItem('roam_token') || '',
  user: JSON.parse(localStorage.getItem('roam_user') || 'null'),
})
```

- 登录/注册成功后写入 token 与 user，并持久化到 localStorage。
- 退出：清两项，跳首页。
- 路由守卫：只有 `/publish` 暂定需要登录；首页、地点页、详情页游客可看。

## 5. Mock 策略

- `src/mock/` 下的数据字段必须与 `API-契约.md` 逐字一致（`camelCase`）；改契约先改 mock。
- `api/post.js`、`api/topic.js` 内用 `const USE_MOCK = import.meta.env.VITE_USE_MOCK !== 'false'` 切换：
  - `true`（默认）：返回 mock，加 200ms 延迟模拟网络；
  - `false`：走真实请求。
- 后端接口上线后只改环境变量，**组件里不出现任何 mock 判断**。

## 5.5 视觉与结构的唯一来源

**`docs/mockup.html` 是视觉与页面结构的唯一规格**：布局、分栏、间距、字号、组件形态都以它为准，不允许自行简化或重排。

对尚未有接口的控件（打分、到这里怎么走、关注、收藏、分享）：

- **保留**，按 mockup 的位置和样式渲染；
- 标记为 disabled（`pointer-events: none` 或 `disabled` 属性），视觉上降低一档；
- 加 `title="P1 上线"` 说明，不做跳转、不发请求。

图片位统一用 mockup 的灰色占位块（`.thumb`），不放大假图。
