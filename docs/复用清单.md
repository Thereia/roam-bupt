## 4. 明确不搬（taco 里存在，但本项目不要）

| 模块 | 原因 |
|---|---|
| `wx/**`（公众号/扫码/支付/菜单）、`pay/**`、小程序 | 与产品无关，占代码量大 |
| 专栏 `column/**`、付费 `ArticlePay`、知识星球白名单 | 一期不做 |
| `shortlink/**`、sitemap/SEO、canonical 过滤器 | 校园内部产品不需要 |
| AI/TIA（`chatai/**`、`ChatService*`、`ai/**`、共识管线） | 按决策完全不做 AI |
| Excel 导出、请求统计、在线人数 | 运营组件 |
| 文章 `article/**`、分类/标签 `category/**`/`tag/**` | 被 `post`/`topic` 取代 |

## 5. 搬的时候要注意的坑（taco 里踩过）

1. **JDK 必须是 17**：本机默认 21 会让 Lombok 注解处理器崩；`JAVA_HOME` 显式指定。
2. **MyBatis-Plus 锁 3.5.10.1 线**：3.5.11+ 移除了 `IService/ServiceImpl`，taco 的 DAO 全都继承 `ServiceImpl`。
3. **本地仓库是 `E:\develop\maven-rep`**（不是 `~/.m2`），新项目要继承同样的 settings。
4. **ES 是 7.17 + 手写 JSON query**（`RestHighLevelClient`），不是 spring-data-es；索引 mapping 里 `titleExact` 之类精确字段是后补的，不要漏。
5. **敏感词库**：`SensitiveService` 依赖自建 `SensitiveWordBs` 实例与 DB 词表，搬过来要带初始词表，否则启动即空转。
6. **通知链路**：taco 的点赞→通知走 RabbitMQ，本地要起 MQ；开关 `rabbitmq.switchFlag` 默认开，保留关掉退化为 Spring 事件的路径。

## 6. 验收标准

- L1 搬完后：`mvn -pl roam-web -am -DskipTests compile` 通过，统一返回/异常/Redis 单测绿。
- L2 搬完后：注册登录、发帖、评论、通知四条链路能端到端跑通（无搜索）。
- 搜索搬完后：发帖 3 秒内可被关键词搜到；ES 停掉时走 MySQL 兜底不报错。
