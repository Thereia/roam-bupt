# 代码级设计基线

> 适用范围：所有域（auth / user / topic / post / comment / notify / search / space / admin）。
> 写第一行代码前必须满足本文件；与本文件冲突的实现按 bug 处理。
> 评审记录：2026-11-18 经接口/生产级两轮评审修订（503 语义、SessionStore 三态、事务副作用、幂等三档、可选认证）。

---

## 1. 分层与依赖

```
web → service → core → api
```

- 禁止反向依赖与跨层跳转（web 不得直接调 DAO）。
- `web` 只依赖 `service` 的**接口**；`service` 不 import `core` 里的 HTTP 类型。
- `core` 不 import `com.roambupt.service.*`，只提供无业务语义的能力。
- `web` 可以使用 `core` 的**注解与接口**（`@Permission`、`SessionStore`），但不得使用 `core` 的内部实现类。
- 转换器（converter）手写在 `service/<domain>/converter/`，不引 MapStruct。

## 1.5 域间协作（横向规则）

纵向分层拦不住跨域耦合，以下五条是硬规则：

1. **禁止 import 其他域的 `repository.*`**；跨域只能调对方的 `*QueryService`（读）或 `*CommandService`（写），入参与返回值都是 DTO/VO，不返回 Entity。
2. **只写自己域的表**：评论不 `update post`，点赞不 `update user`，热度回写由所属域自己做。
3. 事件统一放 `roam-api/model/event/*Event`，**纯 record，不继承 Spring 类型**；发布方注入 `ApplicationEventPublisher`，禁止 `SpringUtil` 静态调用。
4. 消费方一律 `@TransactionalEventListener(phase = AFTER_COMMIT)`。
5. 聚合页（地点页、首页右栏）由所属域的服务组装（如 `TopicDetailService`），Controller 不拼装。

新增一条跨域依赖，必须在本节登记方向与理由。

## 2. 对象边界

| 类型 | 位置 | 规则 |
|---|---|---|
| Entity（DO） | `service/<domain>/repository/entity` | 与表一一对应；只在本层出现，禁止作为 Controller 入参/返回值 |
| DTO | `api/model/dto` | 入参，带 `@NotBlank/@Size/@Min` 校验 |
| VO | `api/model/vo` | 出参，绝不含 password 等敏感字段 |
| Enum | `api/model/enums` | 状态、角色一律枚举，不用魔法字符串 |

## 3. 统一响应与错误码

响应体固定 `ResVo{code, message, data}`。

| code | HTTP | 含义 |
|---|---|---|
| 0 | 200 | 成功 |
| 4001 | 400 | 参数错误 |
| 401 | 401 | **token 无效**（未登录、签名错、已登出） |
| 403 | 403 | 无权限 |
| 404 | 404 | 资源不存在 |
| 409 | 409 | 冲突（重名、状态不允许） |
| 429 | 429 | 请求过频 |
| 500 | 500 | 服务异常 |
| **503** | 503 | **依赖不可用**（Redis 宕机等），与 401 严格区分 |

**401 与 503 的边界是本项目最重要的一条错误语义**：token 本身有问题才 401；认证依赖不可用是 503。前端只对 401 清 token，对 503 提示重试。

## 4. 校验与异常

- 入参 `@Valid`；`MethodArgumentNotValidException` → 4001，取第一条字段错误。
- 业务失败抛 `BusinessException(StatusEnum)`，Controller 不 catch、不拼错误码。
- 禁止 `catch (Exception e) { }` 静默吞异常；必须记日志并转成明确结果。
- 非预期异常记 error 日志，返回 500 且不回堆栈。

## 5. 事务

- 写操作在 **service 实现类**方法上加 `@Transactional(rollbackFor = Exception.class)`。
- **禁止同类自调用**（`this.xxx()` 绕过代理，事务静默失效）；组合逻辑上移到公开编排方法。
- 事务内不做远程调用、不发消息、不写 Redis。
- **跨事务副作用一律在提交后执行**：`@TransactionalEventListener(phase = AFTER_COMMIT)`，禁止在事务方法体内直接 `publishEvent` / 写 Redis / 调 MQ。
- afterCommit 阶段抛异常已无法回滚：必须捕获 + WARN + 落补偿记录，不能让它冒泡。

## 6. 幂等与并发（按语义分三档，禁止一刀切）

| 档 | 场景 | 行为 |
|---|---|---|
| `createOnly` | 注册、发布 | 依赖唯一索引，冲突 → **409** |
| `idempotent` | 点赞、收藏、关注 | 冲突视为成功 → **200**；**只有 `affectedRows == 1` 时才发通知** |
| `upsert` | 评分（改分）、取消关注 | `INSERT … ON DUPLICATE KEY UPDATE`，恒 200 |

- 统一封装在 `core` 的 `DuplicateKeyHandler`，禁止每个 service 各写 try/catch。
- **不做"先查后插"**；并发正确性只依赖 DB 唯一索引。
- 用户名归一化：`trim()` + `toLowerCase(Locale.ROOT)`，禁止空白与大小写变体（`utf8mb4_unicode_ci` 本身大小写不敏感且 PAD SPACE，不归一化会让用户看到"名字被占了但不是我"）。
- 计数类（浏览、点赞数）用 Redis 原子增减，异步落库；落库顺序固定 **先写库 → 成功后删 key → 异常保留 key 待重试**，"读-删-写"会永久丢增量。

## 7. Redis 约定

- key 前缀 `roam:{domain}:`，冒号分隔，例：`roam:session:{jti}`、`roam:heat:post:{id}`。
- **所有 key 必须带 TTL**；无 TTL 的 key 视为 bug。
- 值统一 JSON；用 `StringRedisTemplate`。
- **超时必须显式配置**：连接 1s、命令 500ms（`spring.data.redis.connect-timeout` / `timeout`）。Lettuce 默认 60s，不配等于给 Redis 抖动留了一个雪崩入口。
- 无 `commons-pool2` 依赖时 `lettuce.pool.*` 不生效也不报错，不要写。
- **不提供通用 `RedisClient`**。core 只暴露三个窄接口，TTL 写进签名，让"无 TTL 的 key"在类型上写不出来：
  - `SessionStore`：`save(jti, uid, Duration)` / `lookup(jti)` / `remove(jti)` / `revokeAllOf(uid)`
  - `CounterStore`：`incr(key, Duration)` / `batchGet(keys)`
  - `TtlCache`：`get(key, Supplier<V>, Duration)`
  前缀、序列化、异常翻译全部关在实现里。

## 8. 外部依赖失败语义

| 依赖 | 用途 | 不可用时 | 理由 |
|---|---|---|---|
| Redis | 会话 | **503**（默认 fail-closed）；`roam.auth.redis-fail-open=true` 可降级放行并打 WARN | 认证是安全边界；但不能把"依赖挂了"伪装成"你密码错了" |
| Redis | 计数/缓存 | 跳过，主流程继续 | 非关键路径 |
| Elasticsearch | 搜索 | 降级 MySQL LIKE | 可用性优先 |
| RabbitMQ | 通知 | 落库 + 定时补偿扫描 | 通知不能丢 |
| OSS | 上传 | 返回 500，不做本地降级 | 无可靠降级路径 |
| 路线图数据 | 寻路 | 返回 404/空结果，不抛 500 | 数据缺失≠系统故障 |

### 8.1 上传规则（P0 就要有，因为 `post_media` 已在 P0 表里）

- 类型白名单：`image/jpeg`、`image/png`、`image/webp`；**拒绝 svg**（可携带脚本）。
- 魔数校验：前 12 字节匹配 `FFD8FF` / `89504E47` / `RIFF....WEBP`，不只看 `Content-Type`。
- 单文件 ≤5MB，每帖 ≤9 张；服务端重命名 `{uid}/{uuid}.{ext}`，原始文件名只存不拼路径。
- 发帖时 `media[].url` 必须匹配 `roam.upload.allowed-prefix`，否则 4001（防盗链与 `data:` 伪协议）。

## 9. 鉴权与上下文

- 请求头 `Authorization: Bearer <jwt>`。
- 鉴权三态：匿名 / 可选登录（`@OptionalAuth`，解析失败按匿名，不 401）/ 必须登录。
- 拦截器顺序：解析签名 → 查 `SessionStore` → 查 `user.status` → 写 `ReqInfoContext`。
- `SessionStore` 返回**三态**：`VALID` / `ABSENT` / `UNAVAILABLE`；`UNAVAILABLE` → 503，不能返回 401。
- 签发时同时写 `roam:session:{jti}` 与 `roam:auth:user-sessions:{uid}`（SET，TTL 一致）；封禁/改密/降权时 `revokeAllOf(uid)`，使旧 token 立即失效。
- `ReqInfoContext` 存 `uid` + `role` 快照，`/admin/**` 用快照校验，封禁后 ≤1 个请求生效。
- `ReqInfoContext` 必须在 `afterCompletion` 清理，否则线程池复用时串号。

## 10. 日志与可观测

- 成功事件：`auth.login.success`、`post.create`、`comment.create`。
- **失败与降级事件（必须记）**：

| 事件 | 字段 | 级别 |
|---|---|---|
| `auth.login.fail` | `reason=NO_USER\|BAD_PASSWORD\|DISABLED\|RATE_LIMITED`、`username`、`ip` | WARN |
| `auth.session.reject` | `reason=NO_TOKEN\|BAD_SIGN\|EXPIRED\|NOT_IN_WHITELIST\|STORE_UNAVAILABLE` | INFO/WARN |
| `auth.session.degraded` | `uid`、`path`（fail-open 生效时） | **WARN** |
| `search.fallback` | `es_ms`、`mysql_ms` | WARN |
| `notify.retry` | `notification_id`、`attempt` | WARN |

- 请求级 `rid` 写入 MDC，日志 pattern 带 `%X{rid}`，`afterCompletion` 与上下文一起清理。
- **禁止打印密码、完整 token、手机号**；token 只打 `jti` 前 8 位。
- dev 的 SQL 日志只开慢 SQL（>200ms），避免把正文与密文全量打出来。

## 11. 配置

- 统一前缀 `roam.*`，用 `@ConfigurationProperties` 绑定，禁止散落 `@Value`。
- 敏感项从环境变量读；**dev profile 允许写本地默认值，但必须在文件里注释"仅本地"**，prod 不允许有默认值。
- 功能开关命名 `roam.<domain>.enabled`，默认值写清楚。

## 12. 分页

- 入参：`page` 从 1 开始，`pageSize` 默认 10、最大 50，超限截断不报错。
- 出参：`{ total, page, pageSize, list }`。
- 深分页（page > 100）走游标接口，P0 不做，接口参数里不预留。

## 13. 扩展点登记（**只登记当前阶段有调用方的**）

| 扩展点 | 接口所在包 | P0 实现 | 替换场景 |
|---|---|---|---|
| 会话存储 | `core/session` | `RedisSessionStore`（测试替身 `FakeSessionStore` 只放 test） | 多活/集群 |
| 登录限流 | `core/limit` | `InMemoryRateLimiter`（Caffeine） | 多实例换 Redis 滑窗 |
| 搜索 | `service/search` | `EsSearchService` + `MysqlSearchService` + `FallbackSearchService` 装饰器 | 换引擎/加向量 |
| 通知投递 | `service/notify` | Spring 事件（P1 可切 Rabbit） | 换 MQ |
| 存储 | `service/storage` | `OssStorage` / `LocalStorage` | 换 OSS 厂商 |
| 敏感词 | `core/sensitive`（接口） | `DbSensitiveWordFilter` 放 `service/moderation` | 换词库/算法 |

- **删掉了 `TokenIssuer` / `CredentialVerifier`**：P0–P2 只有 JWT 与 BCrypt 一个实现，属于假接缝；直接写在 `service/auth`，真要换登录方式时再抽。
- `RoutePlanner` **不是可换引擎**，是 `space` 域的深模块，签名固定：`RoutePlan plan(List<RouteStop> stops, TravelMode mode)`；纯函数，图数据由 `RouteGraphProvider` 注入，拥挤度记录拆到 `RouteTrafficRecorder`。
- 禁止为了"扩展性"提前建空骨架；出现第二个实现才登记。
