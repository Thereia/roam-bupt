# 骨架规划（P0）

> 2026-11-17。目标：定下模块划分、包结构、依赖规则、配置与建库方式、首批提交与验收。
> 确认后按 §9 的顺序开工，不再逐文件讨论。

---

## 1. 仓库形态

```
roam-bupt/
├─ pom.xml                 聚合 + 依赖版本统一
├─ roam-api/               实体之外的对外模型：VO / DTO / 枚举 / 异常 / 上下文
├─ roam-core/              基础设施：缓存、工具、权限、敏感词、通用配置
├─ roam-service/           业务：领域包 + DAO + Mapper XML
├─ roam-web/               入口、Controller、全局配置、Liquibase
├─ roam-vue/               前端（Vue 3 + Vite）
├─ docs/                   章程、数据、复用清单、本文件
└─ scripts/                本地启动 / 数据同步小脚本（可选）
```

**依赖方向（单向，禁止回指）**

```
roam-api  ←  roam-core  ←  roam-service  ←  roam-web
   ↑                                          │
   └──────────────────────────────────────────┘
```

- `roam-api`：不依赖任何模块，只带 Lombok、MyBatis-Plus 注解、Jackson 注解。
- `roam-core`：依赖 api；带 Redis、Web（仅用于 `@Component`/过滤器类型）、hutool、敏感词、JWT。
- `roam-service`：依赖 core；带 MyBatis-Plus starter、MySQL 驱动、Caffeine。
- `roam-web`：依赖 service；带 web、validation、liquibase-core、actuator、springdoc。

## 2. 包结构

```
com.roambupt.api.model.{vo,dto,enums,exception,context}
com.roambupt.core.{cache,util,permission,sensitive,common}
com.roambupt.service.<domain>.{repository.entity,repository.dao,repository.mapper,service,converter}
com.roambupt.web
├─ RoamApplication
├─ config
├─ global            # 拦截器、异常处理、Web 配置
├─ front.<domain>    # REST Controller
└─ admin.<domain>    # 后台 REST，全部 @Permission(ADMIN)
```

`<domain>` 一期固定为：`user`、`topic`、`post`、`comment`、`notify`、`search`、`space`。
P0 只落地 `user`、`topic`、`post`，其余包到对应阶段再建（不建空目录）。

规则：

- Controller 不写业务，只做参数校验 + 调 service + 包 `ResVo`。
- Entity 只在 service 层出现，不进 api 包；对外一律 DTO/VO。
- 复杂 SQL 写 Mapper XML（`roam-service/src/main/resources/mapper/<domain>/`），简单查询用 MP。
- 转换用手写 converter（不引 MapStruct，少一层注解处理器与 JDK 版本的坑）。

## 4. 配置

`roam-web/src/main/resources/`：

```
application.yml          # 公共：端口、mybatis-plus、liquibase、自定义前缀 roam.*
application-dev.yml      # 本地：MySQL/Redis 地址，敏感值走环境变量
liquibase/master.xml
liquibase/changelog/*.xml
liquibase/data/*.csv     # 由 docs/data 复制而来，Liquibase loadData 读取
```

关键约定：

- 端口 8080；上下文路径 `/`；API 前缀 `/api/v1`。
- 自定义配置统一挂 `roam.*`：`roam.jwt.*`、`roam.search.*`、`roam.rabbitmq.switch-flag`、`roam.route.*`。
- 敏感信息（DB 密码、Redis 密码）只走环境变量，yml 里写占位。
- 日志：`com.roambupt` 默认 info，SQL 在 dev 下 debug。

## 5. 数据库与 Liquibase

库名 `roam_bupt`，字符集 `utf8mb4`。

changelog 拆分（按阶段追加，不回头改已执行文件）：

```
master.xml
├─ 001_user_topic_post.xml      # P0：user / topic / post / post_topic / post_media
├─ 002_comment_notify.xml       # P1：comment / user_foot / follow / notification
├─ 003_space_rank.xml           # P2：route_node / route_edge / topic_rating / topic_rank
├─ 010_seed_topic_place.xml     # P0：loadData topic_place.csv（145 行）
├─ 011_seed_route_node.xml      # P2：loadData route_node.csv（372 行）
└─ 012_seed_route_edge.xml      # P2：loadData route_edge.csv（446 行）
```

- `001` 里 `topic.id` 不自增：地点用 `source_poi_id`（1–145），分类主题从 1000 起。
- 教室（66）与卫生间（12）导入时 `enabled = 0`，前台不可见。
- 种子 CSV 只在 `resources/liquibase/data/` 存一份；`docs/data/` 保留为导出记录，二者不一致时以 resources 为准。

## 6. 前端骨架

```
roam-vue/
├─ vite.config.js          # dev 代理 /api → localhost:8080
├─ index.html
└─ src/
   ├─ main.js
   ├─ router/index.js      # 10 个路由先占位，P0 只实现 3 个
   ├─ api/request.js       # axios 封装，统一解 ResVo
   ├─ api/index.js
   └─ views/{Home,Topic,Post,Login}.vue
```

P0 只要求：能起 dev server、能登录、首页能拉到帖子列表、地点页能显示内容。
不引 UI 库，样式沿用 `docs/mockup.html` 的视觉基调（纸色 + 墨绿）。

## 7. 测试策略

| 层 | 内容 |
|---|---|
| service 单测 | 每个 service 至少 1 条核心路径（发帖、挂主题、登录） |
| web 冒烟 | 1 个 `@WebMvcTest` 或 `@SpringBootTest` 覆盖登录 + 发帖 |
| DB | 测试用同一套 Liquibase 建库（独立 schema `roam_bupt_test`），不 mock |

P0 不追求覆盖率，只保证"改坏了能立刻知道"。

## 8. 启动与构建

```bash
# 环境
JAVA_HOME=E:\develop\java            # 17.0.12，不能用 21
MAVEN=E:\develop\apache-maven-3.9.11\bin\mvn.cmd
# 本地仓库 E:\develop\maven-rep（settings.xml 指定）

# 编译
%MAVEN% -pl roam-web -am -DskipTests compile

# 起服务（需先 install 各模块 SNAPSHOT）
%MAVEN% -pl roam-web -am -DskipTests install
%MAVEN% -pl roam-web spring-boot:run
```

## 9. 开工顺序与提交

| # | 提交 | 内容 | 结束标志 |
|---|---|---|---|
| 1 | `chore: 初始化多模块骨架` | 父/子 POM、目录、`.gitignore`、`.gitattributes`、`README.md` | `mvn -DskipTests compile` 通过 |
| 2 | `feat(db): Liquibase 基线表与地点 seed` | 001/010 changeset、数据复制 | 启动即建表并导入 145 条地点 |
| 3 | `feat(auth): 注册登录与 JWT 会话` | user 域、JWT、Redis 会话、拦截器 | 注册→登录→带 token 访问受保护接口 |
| 4 | `feat(post): 发帖与地点页最小链路` | topic/post 域、发帖接口、地点页查询 | 发一条挂地点的帖子，地点页能查到 |
| 5 | `chore: 前端骨架与联调` | Vite 工程、三个页面、代理 | 本地前后端跑通登录与列表 |

每个提交都必须能独立编译；2 之后每次提交前跑一次 `liquibase update` 验证。

## 10. 需要你点头的三处

1. **包名 `com.roambupt`**（不是 `cn.edu.bupt`，也不带连字符）。
2. **前端目录 `roam-vue`**，P0 只做骨架。
3. **不引 MapStruct / knife4j**，用 springdoc。

有异议现在改成本最低；没异议我按 §9 第 1 步开始。
